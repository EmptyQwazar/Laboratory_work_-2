## Задание 1

### Задача 3

Текст задачи:
Дан набор целых чисел с четным количеством элементов. Заполнить вектор V исходными числами, вывести вначале вторую половину элементов вектора V, а затем первую половину (в каждой половине порядок элементов не изменять).

Алгоритм решения:
1. Запросить у пользователя четное количество элементов numElements (с проверкой корректности ввода).
2. Создать вектор v и заполнить его числами, введенными с клавиатуры.
3. Вычислить середину вектора: создать итератор mid, сдвинутый от начала (begin()) на numElements / 2 позиций.
4. Вывести элементы от mid до end() (вторая половина).
5. Вывести элементы от begin() до mid (первая половина), используя итераторы.

## Задание 2

### Задача 3

Текст задачи:
Дан список L, количество элементов которого делится на 3. Добавить в конец списка первую треть его исходных элементов в обратном порядке. Использовать один вызов функции-члена insert.

Алгоритм решения:
1. Запросить количество элементов numElements (кратное 3) и заполнить список l.
2. Вычислить размер одной трети: thirdSize = numElements / 3.
3. Пройти по списку от начала thirdSize раз, скопировав элементы в промежуточный вектор firstThird.
4. Одним вызовом l.insert(l.end(), firstThird.rbegin(), firstThird.rend()) вставить элементы из вектора в конец списка. Использование обратных итераторов (rbegin, rend) обеспечивает вставку в обратном порядке.

## Задание 3

### Задача 10

Текст задачи:
Дан список L с элементами A1, A2, ..., AN (N — четное). Изменить порядок элементов на следующий: AN, A1, AN-1, A2, AN-2, ..., AN/2, AN/2-1. Использовать функцию-член splice с двумя итераторами.

Алгоритм решения:
1. Заполнить список l четным количеством элементов.
2. Создать два итератора: i указывает на начало (куда вставлять), r указывает на последний элемент (std::prev(l.end())).
3. В цикле numElements / 2 раз вызывать l.splice(i++, l, r--). Это вырезает элемент с конца и перемещает его в начало.
4. Чтобы сохранить элементы A1, A2... на своих местах, после каждой вставки (кроме последней) делать ++i, пропуская «родной» элемент списка.

Алгоритм решения:
1. Заполнить вектор v.
