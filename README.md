Текст задачи:
Дан набор целых чисел с четным количеством элементов. Заполнить вектор V исходными числами, вывести вначале вторую половину элементов вектора V, а затем первую половину (в каждой половине порядок элементов не изменять).

Алгоритм решения:
1. Ввести четное число элементов с проверкой ввода.
2. Создать вектор v заданного размера и заполнить его с клавиатуры через итератор в цикле.   
3. Найти середину вектора: mid = v.begin() + v.size() / 2.   
4. Вывести элементы от mid до v.end() (вторая половина).   
5. Вывести элементы от v.begin() до mid (первая половина).
